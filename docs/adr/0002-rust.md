# Heighliner is written in Rust

Go looks like the obvious choice, since Tailscale and Syncthing are both Go.
Heighliner links neither of them, though. It drives Syncthing through its REST
API, and it talks to the host's `tailscaled` through a few local API calls such
as `whois` and `status`. Go's library advantage therefore comes down to a small
HTTP client.

The hard part of heighliner is getting reconciliation and the configuration
merge right. Rust's sum types and exhaustive matching help most there.

## Consequences

Heighliner keeps its own Tailscale local API client. That API is not officially
stable, so the client stays small and isolated.
